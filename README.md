# Mi proyecto Android – Noche

Pantalla de inicio para Android (Java) con tema de noche estrellada.

- **Idiomas:** español (por defecto), inglés, francés, alemán y portugués.
- **Tamaños y orientación:** `layout` vertical, `layout-land` horizontal (luna a la izquierda, texto a la derecha) y medidas distintas para teléfono, tablet de 7" y tablet de 10" / TV.
- **Fondo nine-patch:** `drawable-nodpi/fondo_noche.9.png` (cielo con estrellas y montañas que se estira sin deformarse).

## Cómo abrirlo
Abre la carpeta en Android Studio (*File > Open*), espera a que Gradle sincronice y ejecuta en un emulador.
